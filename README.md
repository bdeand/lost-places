# Lost Places

An interactive website exploring abandoned and forgotten places around the world.

## About

Lost Places is a simple web project created to showcase abandoned cities,
buildings, villages, and other forgotten locations through real photographs
and short stories.

## Features

- Explore abandoned places around the world
- Search for locations
- Filter places by category
- View detailed stories in interactive popups
- Responsive design
- Real photographs
- Interactive contact/suggestion form

## Technologies

- HTML5
- CSS3
- JavaScript
